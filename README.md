### Prerequisites
Please use the provided **Dev Container** for a simpler setup.

- Java 21+
- Maven
- Node.js 24

### Install dependencies

```bash
make install
```

### Run the project

```bash
make backend # http://localhost:5173/
make frontend # http://localhost:8080/api
```
