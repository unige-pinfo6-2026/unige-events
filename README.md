### Prerequisites
- Java 21+
- Node.js 18+
- Maven

### Run the project

**Backend**: http://localhost:8080
```bash
cd backend && ./mvnw quarkus:dev
```

**Frontend**: http://localhost:5173
```bash
cd frontend && npm install && npm run dev
```
