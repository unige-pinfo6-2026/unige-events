# Docker Files

This directory contains Dockerfile templates provided by Quarkus default configuration.

These Dockerfiles are generated automatically by Quarkus and support different build modes:

- **Dockerfile.jvm** - Standard JVM mode
- **Dockerfile.legacy-jar** - Legacy JAR packaging
- **Dockerfile.native** - Native executable build
- **Dockerfile.native-micro** - Minimal native executable build

For more information about Quarkus container images, see the [Quarkus documentation](https://quarkus.io/guides/container-image).
